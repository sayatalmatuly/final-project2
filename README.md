# TimeManager

Учебный проект для управления временем и задачами. Я сделал его чтобы было удобно планировать день и отслеживать продуктивность без лишних сложностей. Дизайн минималистичный и строгий.

Особенности проекта
* Планировщик задач с привязкой к времени и категориям
* Pomodoro таймер который помогает фокусироваться на работе
* Калькулятор продуктивности с круговым графиком
* Страница с рекомендациями где собраны полезные ресурсы
* Все данные сохраняются локально прямо в браузере

Технологии
* HTML5 и CSS3
* Чистый JavaScript без фреймворков
* Lucide для иконок
* Canvas API для построения графиков

Как запустить
Тут нет никаких сборщиков и бэкенда. Нужно просто скачать файлы и открыть index.html в любом браузере. Скрипты и стили сами подтянутся.

Структура
* css/main.css содержит все стили
* js/app.js отвечает за всю логику страниц
* HTML страницы для разделов сайта
